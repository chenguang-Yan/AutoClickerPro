# Auto Clicker Pro · 鼠标自动点击器

一款 Windows 桌面端的多坐标批量鼠标自动点击器，深色科技感界面，**零第三方依赖**
（仅使用 Python 标准库 `tkinter` + `ctypes` 调用 Win32 API，无需安装任何库）。

> 所有点击通过 `SendInput` 以绝对坐标下发，并在启动时启用系统 DPI 感知，保证坐标 1:1 精确。

---

## 启动方式

- **方式一（推荐）**：双击 `dist\AutoClickerPro.exe`（或双击 `run.bat` 一键启动）
- **方式二（源码运行）**：`pythonw auto_clicker.py`（需本机 Python 自带 tkinter）

> 若要点击以管理员权限运行的程序（如某些游戏、安装器），请对本软件右键「以管理员身份运行」。

---

## 界面布局

窗口约 **642 × 450**，深色科技风，自上而下分为三块：

| 区域 | 内容 |
| --- | --- |
| 顶栏 | Logo + 标题「AUTO CLICKER PRO」+「帮助」按钮 |
| 左栏「点击坐标序列」 | 坐标表格 + 工具按钮 + 添加坐标文字提示 |
| 右栏「运行参数 / 运行选项 / 全局快捷键」 | 参数卡片、复选项、快捷键标签（固定高度，无需滚动） |
| 底栏 | 固定宽度的「开始」按钮 + 右侧状态信息 |

## 功能详解

### 一、点击坐标序列（左栏）

坐标按顺序**从上到下循环执行**。表格列：`#` / `X 坐标` / `Y 坐标` / `点击类型` / `间隔(ms)`。

| 操作 | 方法 |
| --- | --- |
| **添加坐标** | 把鼠标移到目标位置，按 **F8**（拾取坐标，可在右上改键）；坐标框上方有青色文字提示 |
| **编辑数值** | **双击** `X 坐标` / `Y 坐标` / `间隔(ms)` 单元格直接输入 |
| **修改类型** | **双击**「点击类型」单元格，下拉选择四种类型之一 |
| **删除** | 选中行 → 点「删除」按钮 / 按 `Delete` 键 / 右键菜单「删除选中坐标」 |
| **清空** | 点「清空全部」按钮（会二次确认） |
| **排序** | 「↑ 上移」「↓ 下移」调整执行顺序 |
| **复制** | 右键菜单「复制该坐标」 |
| **保存/恢复坐标** | 见第七节「配置与坐标的存取」 |

> 每个坐标的「间隔(ms)」**留空 = 使用全局点击间隔**；填入数字则单独覆盖该点的等待时间。

### 二、运行参数（右栏 · 运行参数区）

以两列卡片网格呈现，标签在上、输入框在下：

- **点击间隔(ms)**：相邻两次点击之间的等待时间，`1000 = 1 秒`，最小 0 ms。
- **双击间隔(ms)**：执行「双击」时两次按下之间的间隔，默认 `60` ms。
- **循环次数(次)**：`0 = 无限循环`；填正整数则达到轮数后自动停止。
- **默认点击类型**：决定新拾取坐标的默认类型（单个坐标仍可在表格里单独覆盖）。

### 三、运行选项（右栏）

- **平滑移动**：开启后用多段插值模拟真人移动轨迹（关闭则为瞬时跳转）。
- **窗口置顶**：软件窗口始终显示在最前端。
- **启动后最小化**：点击开始后自动最小化到任务栏，运行结束自动还原。

### 四、点击类型

支持 **左键单击 / 右键单击 / 左键双击 / 右键双击** 四种。
「默认点击类型」决定新坐标的类型，单个坐标可在表格里双击「点击类型」单元格单独覆盖。

### 五、全局快捷键（右上 · 可自定义）

| 功能 | 默认键 | 说明 |
| --- | --- | --- |
| 拾取鼠标坐标 | `F8` | 记录当前鼠标位置为一个坐标点 |
| 开始 / 停止 | `F9` | 运行中再按一次即停止 |

- **改键**：直接点击右侧的快捷键标签，会弹出捕获窗口，支持 `Ctrl / Alt / Shift / Win + 普通键`（例如 `Ctrl+F8`）。
- **紧急停止**：运行中按 `F9` 或窗口内 `Esc` 即可停止。

### 六、开始 / 停止 与状态栏（底栏）

- 左下「开始」按钮为**固定宽度**（约 150px），右侧为状态信息，二者互不挤压。
- 点「开始」或按 `F9` 即开始运行；运行时节按钮变绿并显示 **「● 运行中」**，再次点击或按 `F9` 即停止。
- 状态栏显示：`坐标 N 个 · 已执行 N 次点击 · 第 N 轮`；临时提示（如「已记录坐标 (x, y)」）会以青色高亮显示约 2 秒后恢复。

### 七、配置与坐标的存取（分离设计）

参数与坐标采用**分离保存**策略，避免误触与互相干扰：

| 类别 | 保存方式 | 文件 | 说明 |
| --- | --- | --- | --- |
| **运行参数** | 改动后**自动保存** | `autoclicker_config.json` | 含点击间隔、双击间隔、循环次数、默认类型、运行选项、快捷键；启动自动读取 |
| **坐标** | **手动保存**（点「保存」） | 用户指定，默认 `coordinates.json` | 不自动保存；**关闭软件后坐标自动清空** |

- 坐标常变动，单独存成文件便于保存多套坐标方案；需要恢复时在点「导入」选择该 JSON 即可。
- 参数频繁但稳定，自动落盘免去手动操作，下次打开即恢复上次的设置。

> 设计意图：参数修改后即生效并记忆，坐标则需要你主动「保存」才留存，关闭时不污染历史坐标。

## 使用技巧与注意事项

- **DPI 精确**：软件启动即启用系统 DPI 感知，多屏 / 高分辨率下坐标依旧 1:1 准确。
- **管理员程序**：点击以管理员权限运行的窗口时，本软件也要以管理员身份运行，否则点击可能失效。
- **坐标清空**：关闭软件后坐标列表会被清空且不写入配置文件，纯属运行态数据；想长期保留请用「保存」。

## 目录结构

```
auto_clicker.py          主程序源码（tkinter + ctypes）
app.ico                 应用图标
gen_icon.py             图标生成脚本
run.bat                 一键启动批处理
preview.png             界面预览图
screenshot.py           窗口截图验证脚本
dist/AutoClickerPro.exe 打包后的独立可执行文件
autoclicker_config.json 自动保存的参数（首次运行后生成）
coordinates.json        手动保存的坐标（由你点「保存」时生成）
```

## 重新打包

```bat
pyinstaller --noconfirm --clean --onefile --windowed ^
  --name AutoClickerPro --icon app.ico --add-data "app.ico;." auto_clicker.py
```

打包后在 `dist/` 下生成单文件 `AutoClickerPro.exe`，可独立拷贝到其他 Windows 机器运行。
